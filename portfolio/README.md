- 📱 **100% Responsive & Cross-Device Compatible**: Fluid on mobile phones, tablets, laptops, and ultra-wide gaming monitors.

## 🚀 How to Open and Run

### Option 1: Instant Local Browser View (Zero Setup)
Simply double-click `index.html` or right-click and choose **Open with Chrome / Edge / Firefox**. It runs instantly with zero build steps or server requirements!

### Option 2: Live Server (VS Code / Python)
If you use VS Code:
1. Open the `portfolio` folder in VS Code.
2. Click **Go Live** with the Live Server extension.

Or run via Python in terminal:
```powershell
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## 🌐 How to Deploy for Free (To Share Online)

### Method 1: GitHub Pages (Recommended)
1. Create a free repository on [GitHub](https://github.com) named `portfolio` or `anandu-portfolio`.
2. Push or drag-and-drop the files (`index.html`, `css/`, `js/`, `README.md`) into the repository.
3. Go to **Settings > Pages** and select `main` branch -> **Save**.
4. Your portfolio will be live at `https://<your-username>.github.io/portfolio/`!

### Method 2: Netlify / Vercel
1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop the `portfolio` folder.
3. Get a live public URL in 10 seconds!
